# PreceptorMED

SaaS de educação médica para estudantes brasileiros. Live em https://thepreceptor.com.br

## Stack

React 18 + Vite + TS + Tailwind + shadcn/ui (frontend) · Supabase Postgres + Edge Functions Deno (backend) · Claude Opus 5 via API da Anthropic (IA) · Vercel (deploy)

## Desenvolvimento

```sh
npm i
npm run dev   # porta 8080
npm run build
```

Detalhes de arquitetura, convenções e pitfalls em [`CLAUDE.md`](./CLAUDE.md).
